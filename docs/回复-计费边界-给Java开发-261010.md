### 1.5 「共享表只做加减」

认。我们写账户 / 批次时本来就是：同一事务内先 `SELECT ... FOR UPDATE` 锁账户行，再按「预留单 → 账户 → 批次」顺序加锁（批次按过期先后、同期按 id 排序）；写的时候用相对更新（`balance = balance - ?` 这种），不是读出来整值写回。
文档里「只做加减就不用锁」的表述已改成你们建议的那句：**任何写账户或批次的操作，都必须在同一事务内先锁账户行，再按「账户 → 批次」顺序加锁**。
