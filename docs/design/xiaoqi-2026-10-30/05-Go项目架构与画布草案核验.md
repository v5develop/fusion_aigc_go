# fusion_aigc_go 架构摸底 + 画布草案核验（Agent D 产出，浓缩）

## 架构事实
- 服务：copywriting-rpc 9201 / digitalhuman-rpc 9202(+Poller) / note-rpc 9203(+Poller) / imagegen-rpc 9204(+Poller+计费 Reclaimer) / gateway-api 8888 (/api/v1/local-life/*) / admin-api 8889 / app/media 18090（Java、Go、ai-gateway 三方共用媒体服务）。
- 数据层：go-zero sqlx + goctl 生成 model（*_gen.go + *_model.go 自定义 CAS 方法 `WHERE status=?`）；无 bun/gorm。
- 轮询器套路（note flow.go:99-237）：5s 扫生成中 → Billing.Renew 续期 → aigc.GetResult → Storage.Transfer 转存公有桶 → 先 Billing.Settle 再交付 → CAS 终态 → Asset.InsertSet 入库 → TaskCenter.Sync。
- pkg：aigc（仅执行面 /aigc/generate + /aigc/getRes，task_type 9/70/.../92，无取消，无 HMAC/catalog）；billing（直接写 Java 账表 afv_points_*/afv_billing_reservation*，Hold/Settle/Done/Fail/Renew/CheckAccess/RefundConfirmed，biz_type=LOCALLIFE，幂等键 golife: 前缀，0 点报错 price.go:192）；taskcenter（Source+Syncer，INSERT…SELECT…ON DUPLICATE KEY 整批收敛同步 afv_creation_task，4 个调用方 note/copywriting/digitalhuman/imagegen）；asset（写 afv_asset/afv_asset_item source_type=2，Conf.Enabled 默认关）；storage（OSS STS 直传、Owned 校验、Transfer）；mediasvc（只有 CoverURL）；llm（纯文本，无多模态）；idempotency（仅请求头归一 Idempotency-Key 优先，去重靠业务表 uk_user_request）；session/token（Redis fusion:token:{access} 与 Java 共用）。
- Java 边界：新表 afv_ 前缀不 ALTER 现有表；Go 写 afv_creation_task(_text)、afv_asset(_item)、afv_billing_*、afv_points_*、afv_app_user、afv_workspace*、afv_team*；Go 完全不访问 afv_image_task/afv_video_task/afv_workflow_*；Java 扫描器只处理 origin_service IS NULL，isLocalLife 只认 LOCAL_LIFE（后台重做/强制失败转发给 Go 靠它）；契约：HTTP 一律 200（401 除外），信封 {code,reason,msg,data}，字段下划线，时间 unix 毫秒，新错误码先在 Java ErrorCode 登记；nginx /api/v1/local-life → Go，/api/v1/ → Java；迁移 Go_V<x.y.z>__*.sql 数字排序，最新 Go_V1.0.20，新表必须 COLLATE=utf8mb4_unicode_ci。
- 上游：AIGC 执行面（Python，不回调，无取消，无通用文生图/编辑/扩图/放大）；ai-gateway（独立仓库，/v1/calls、cancel、batchGet、catalog/model-groups、ledger/costs；operations image.generate/edit、video.generate、chat.completion；model_groups img.gpt-image-2/img.seedream-5-pro/img.nano-banana-2.1/vid.seedance-2.5；HMAC 7 头；**调用方只登记 fusion-java/fusion-java-admin，Go 侧零客户端**）。
- media 服务可复用：image/crop（像素框 ≤64 或 rows×cols）、image/grid（1–9 宫格）、image/resize、image/conform、image/mark、watermark、ingest、probe；写操作带 Idempotency-Key，输出 rid，purpose 决定桶（asset_library 公有）。需给 pkg/mediasvc 补方法。

## 草案核验要点（32 条，约一半不符）
- 不实：pkg/aigc 是 ai-gateway 客户端（否）；catalog 缓存（无）；bun 与现状一致（无 bun）；Java 对 afv_creation_task 只读（是主表）；afv_image_task 等「只读」（Go 根本不访问）；SQL 示例 PG 语法 ON CONFLICT…EXCLUDED（MySQL 跑不了）；CreationTask 主键 task_id（主键是 id）；Go_V2.0.1 不存在且跳序；X-Request-Id 幂等（过时，用 Idempotency-Key）；/api/v1/canvas 前缀（落 Java）；HTTP 409/422 + 小驼峰 + ISO8601（违反现网约定）；0 元 Offer 内测（price 门禁拒绝，用 BILLING_MODE=off/shadow）；取消转发（执行面无取消）；反推 chat.completion(vision)（pkg/llm 纯文本）。
- 属实：taskcenter 字符串 SQL（但是有意的整批收敛设计）；pkg/billing bizID SHA-256；asset source_type=2；storage.Owned；Poller 重启续跑；goctl 参数化。
- T0 重构 taskcenter 为事件式 Upsert：不建议——丢 Reclaimer/RefundConfirmed 导致的计费状态收敛、deleted 单调性、失败自愈；漏了 note 调用方。画布只需加一个 taskcenter.Source{Table: afv_canvas_node_run, Prefix: cv, ...}。
- origin_service=CANVAS 有坑：isLocalLife 只认 LOCAL_LIFE → 后台重做/强制失败不转发。用 LOCAL_LIFE + 前缀 cv，或与 Java 约定新值。
- 独立 canvas-api REST：与套路不符，推荐 canvas-rpc + gateway-api 路由（鉴权/幂等/信封中间件都在 gateway）。
- SSE 事件表过度；现网一律轮询。
- 裁剪「前端为主」遗漏 media image/crop、image/grid。
- 提示词库/模板新表与 Java afv_prompt*/afv_creation_prompt/afv_creation_template、Go 惯例 afv_public_template_assets 有重叠。
- 遗漏：ai-gateway 接入全部工作（HMAC 客户端、调用方登记、mr:// 产物现签/复制、retry_safe/409、ledger 对账）；计费 offer/variant 配置、audit Targets、视频 200 分钟预留、扇出计费粒度；admin origin_ref；exec_submission 快照等价物；asset_category_entry 归属；task_id 前缀无下划线；mock；COLLATE；mkconf/install.sh。

## 关键风险
执行能力不存在（gateway 不认 Go 调用方，P0 跨团队）；事件式投影丢计费状态；共享表并发写倒序；一个幂等键对多节点撞 uk_biz（每 node_run 派生 RequestID）；路由与契约冲突；取消不可兑现（口径改为停止跟踪并退款）；SQL 示例照抄即错；0 元内测与门禁冲突。
