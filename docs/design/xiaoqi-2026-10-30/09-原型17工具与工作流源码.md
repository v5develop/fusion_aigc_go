# 原型 17 工具页 + 工作流源码（Agent F 产出，浓缩）

## 要点
- 原型全部提交是本地桩（api/tools.ts 延时 300ms 假 taskId，无轮询；trackTasks 2.6s 后置 succeeded 塞样例图）；工作流 submit() 不调任何 API 直接 push 本地 succeeded 记录。
- 页面提交的是 previewUrl（blob:），不是 remoteUrl → 接后端所有页面需改取 remoteUrl。
- api-contract.json：FieldType TS 声明 14 种，实际用 12 种（不是 11）；accept 是扩展名串非 MIME；**visibleWhen 被丢掉**（姿态 upload_1 仅 mode=reference 可见）。
- 公共上限：图 10MB JPG/PNG/WEBP/GIF；视频 500MB MP4/MOV/WEBM 2–300s；批量 20；参考图 9；工具 count 1-9；工作流 1-4；提示词 3000；本地生活 2000/200；文字替换每处 100；自定义宽高 64-8192。
- 内部值小写 1k/2k/4k、720p/1080p/2k/4k；契约大写；后端需约定。

## 四档图片模型（model-configs.defaults.ts，modelId=model 值）
general 通用(1k:2,2k:3,4k:4) / gpt-image-2 GPT(同) / nano-banana Banana(1k:2,2k:4) / seedream-5-pro Seedream(2k:5,4k:8, 无 1:1)。比例回落 5 档 vs schema 10 档。只有 image-generate 与 posture-fission 露出模型下拉；首屏/场景 schema model:false 但页面仍传 model=general。
视频四档 dreamina-seedance-2-5 / 2-0 / 2-0-fast / 2-0-mini（mini 不支持参考视频）；duration 离散 5/10 vs 真实 [min,max]。

## 17 工具桩入参（即前端将提交的 payload）
dewrinkle {imageUrl} 逐张；retouch {imageUrl} 逐张；upscale {imageUrl,resolution} 逐张；erase {originalImageUrl,maskUrl}（MaskCanvas 导出黑底白笔 PNG 原图尺寸，蒙版需上传；不存历史）；cutout {imageUrl} → {kind:done,url}|{kind:pending,taskId}（done 不进历史，输出透明 PNG）；imageTranslate {imageUrl,targetLanguage} 逐张（前端不渲染文字块）；textReplace 先 recognizeImageText{imageUrl} 同步 [{targetText,text,textRectangles}] 单独计费，再 {imageUrl,textInformation[]} 只传改过的项；ratioConvert {imageUrls[],aspectRatio?,resolution?}|{imageUrls[],width,height} 整批一次（自适应=adaptive；自定义存 "W×H"）；productReplace {originalImageUrl,productImageUrl} 逐张共用素材，无 index；modelTryon {clothImageUrl,modelImageUrl} 逐张；postureFission {mode,imageUrl,content?,referenceImageUrl?,resolution,aspectRatio,num,model}（mode 不进历史）；imageGenerator {content,imageUrls[],resolution,aspectRatio,num,rewritePrompt,model,fixedModel?}；firstScreen {content,imageUrls[],resolution,aspectRatio,num,language,model}（未传 rewritePrompt）；backgroundGenerator {imageUrl?,content,resolution,aspectRatio,num,model}；videoEnhance {videoUrl,resolution}（估价 秒×单价 前端读时长）；videoTranslate {videoUrl,language,voiceModel,voiceKey,addSubtitle,eraseOriginalSubtitle}（voiceKey/布尔不进历史；音色本地 6 条假数据，真实 /voices/list）；videoGenerator {model,duration,content,videoUrl?,imageUrls[],resolution,ratio,generateAudio,rewritePrompt,superResolution}。
逐张提交：for 循环 await，单张失败不中断，连续失败 3 次停。

## 工作流
库存 40 条（id 1–41 去 9）；可见 13：wf:2,3,4,5,8,10,11,12 + 6,7,41 + 13,14；wf:1 单独隐藏；fresh/series/rework/additional 整类隐藏。wf:13=visual-style-replace 单图复制；wf:14=visual-sku-replace SKU替换(withContent)。
提交 payload（本地）：{taskId,title,status,prompt:effectivePrompt,promptOptions{controlIndex:value},referenceContents[{url,content}](仅 wf:14 稀疏按 URL),inputImageUrls[](按 inputs 顺序拍平),inputVideoUrls[],model,resolution:'2k',aspectRatio 模板 defaultRatio,num(wf:13 恒 1)}。
effectivePrompt：模板 HTML 控件（flow_dom input/select/color）渲染为文本 + 卖点/补充要求 \n 连接；带控件 13 条全在隐藏类 → 当前可见集合无提示词控件。
前端无 itemPrompts 字段；referenceContents 稀疏按 URL 需后端按 url 对回 inputImageUrls。wf:13 前端恒 num=1 vs B14 max(prompts,product) 冲突。
角色容量 schema 4/9/9/9 vs adapter 注释 REA 实测 1/3/4/4。
回填：按角色 maxNum 顺序切 inputImageUrls（须保序且张数一致）。
