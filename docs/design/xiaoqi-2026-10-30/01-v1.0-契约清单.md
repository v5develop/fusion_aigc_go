## B 通用接口面
- 信封 {code:0,message,data}；Bearer token；越权一律 404；2 QPS 轮询；同时运行 ≤4；429 带 retryAfter；图片超时 180s 视频 900s；任务保留 90 天结果 30 天。
- 错误码：0/40101/40301/40401/40901(conflictTaskId)/42201(field,reason)/40201(shortfall)/42901(retryAfter)/50001(retryable, 502)/50002(reason, 451)/50301。
- /meta/tools → items[{schemaId,name,kind,route,fieldCount,uploadCount}]；/meta/tools/{id}/params → {schemaId,version,fields[],uploads[]}，11 种 type: text/textarea/select/chips/switch/number/stepper/preset/mask/region-list/section-list/upload；/meta/workflows/{id} 无样例；/meta/models?target= → items[{value,label,default,unit,eta}]。
- POST /uploads multipart file → {url,name}，图 ≤10MB 视频 ≤500MB，URL ≥24h。
- POST /tasks (Idempotency-Key; {target, params}) → 202 {taskId,batchId?,status,cost,balance}；GET /tasks/{id} → {taskId,batchId,parentTaskId,index,target,status,progress,message,cost,error{code,message,retryable},results[{index,url,thumbUrl,width,height,mime,duration?,sectionKey,textRegions[{text,targetText?,textRectangles[{x,y,w,h}]}]}]}；GET /tasks/batches/{id} → {batchId,batchStatus queued/running/partial/succeeded/failed/canceled,tasks[]}；cancel 两个。
- 幂等 owner+target+key 24h；子任务 key#index。
- 计费：冻结→扣减→退款，point_ledger type freeze/charge/refund。
- GET /history?scope=tools|workflow|local-life&cursor&limit → {items[{id,createdAt,status,target,title,inputUrls[],params,results[],cost,batchId?}], nextCursor}；按 batchId 聚合。
- /assets?kind&source&q&page&pageSize → {items[{id,name,kind,source,url,thumbUrl,favorite,createdAt}],page,pageSize,total}；/assets/categories → [{key,label,count}] key model/scene/makeup/hair/accessory/uncategorized；PATCH 改名/收藏；POST 登记；DELETE 软删。宿主路径 /asset/all、/asset/categories。
- /local-life/archives → items[{id,name,createdAt,avatarText,templateCount}]；/archives/{id}；/templates?archiveId；POST /price {archiveId,sections[{key,count}]} → {total,rows[{key,label,unit,count,total}]}。
- point_ledger 只有表无接口；前端桩 GET /balance → {points}。
