## 画布（v1.0 不验收，v1.1）
- 草案 CV 与原型差别大：原型 workflowId 字符串；文档 = Vue Flow 原生 {nodes[{id,type,position,data}], edges[{id,source,target,sourceHandle,targetHandle,data{order}}]}，无 inputRefs/viewport；乐观锁 revision 字符串 + If-Match/ETag，force 覆盖；**前端逐节点编排**（拓扑序串行 runNode），后端只收单节点 run：POST /api/workflows/{wf}/nodes/{node}/run（Idempotency-Key=runId）→{requestId}；GET /api/runs/{requestId}；POST /api/runs/{requestId}/cancel；轮询 1.2s，图 5min 视频 15min；候选 data.candidates[]+selectedCandidate，候选可单独连线 candidate-N。
- 节点：text / image(kind input|result) / video(video-input) / model(kind model 图 | kind video 视频 | inputOnly 参考视频) / tool(crop|upscale|outpaint|i2p|mask|tryon) / module(模板分组框)。**工具节点全是浏览器本地伪实现**（裁剪 canvas、放大拉伸、扩图返原图、反推固定文案、重绘返原图、试穿回填模特图）。
- model data：model 图 Banana/Image/SD5P 视频 Seedance 2.5/2.0/Fast/Mini；modelId image-v1/banana-v1/sd5p-v1/seedance-2-5...；ratio 10 档/视频 3 档；size 1K/2K / 720p/1080p/4K；quality low/medium/high；count 1-4；duration 4s/6s/8s；sound；cfg 0.95；capabilities；maxImageRefs（Image 14/Banana 5(3)/SD5P 3/视频 2 或 3 不一致）。运行态 status/progress/runId/candidates/image/video/assetId 混在 data 里随快照保存。
- RunNodeRequest {workflowId,nodeId,runId,model,modelId,kind,prompt,references[{handle prompt|image|video|audio,index,nodeId,text?,image?,video?,assetId?,mediaId?,sourceHandle?,candidateIndex?}],ratio,size,quality,duration?,sound?,count,cfg}；RunNodeResult {requestId,runId?,status queued|running|succeeded|failed|cancelled,candidates[],videoUrl?,credits,model,progress?,error?,errorCode?,retryable?}。
- 连线规则：prompt←text/i2p(1)；image←image/model/video/tool(≤maxImageRefs)；video←视频 model(1)；image1/image2 各 1；garment 1 models 9；image-in 1；不自连不成环。
- 自动入库：成功后 assetApi.create source generated，kind 继承上游或 scene，title "{model} · {节点} HH:mm"，每候选一个 version，relatedIds 上游 assetId，provenance{runId,workflowId,nodeId,operator,model,params}。「存入资产库开关」源码无 UI。
- 持久化：GET /api/workflows → [{id,title,updatedAt,nodeCount,cover}]；POST {title}；GET/PUT /api/workflows/{id}/canvas（If-Match, 409）；DELETE；另存为前端组合；POST /api/uploads multipart → {id,url,name}（图 30MB 视频 200MB 与 PRD 10/500 不一致）；自动保存 400ms 防抖；Web Locks 单标签。
- 模板 3 个硬编码（outfit 模特换装 / three-view 商品三视图 / element-replace 元素替换），从模板建画布或插入子图（module 包裹），引用演示资产 id。
- 资产面板：本画布节点列表（纯前端）+ 素材库导入（全局资产库）+ 面板内上传。「用于画布」/canvas?asset=&version=；工具页「发到画布」/canvas?image=&title=&prompt=&asset=。
- /canvas-official = 开源 infinite-canvas v0.20.0 iframe，IndexedDB，与自研 Vue Flow 版互不相干；后端只针对自研版。
- 假价 data/canvasPricing.ts；不扣积分。
