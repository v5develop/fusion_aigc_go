# AIGC 本地生活 · 产品说明

> 2026-10-14 · 按当前已实现的功能整理，给产品、运营、测试看。
> 接口细节见 `api-app.md`，部署见 `deploy/server/README.md`。本文只讲「能做什么、怎么用、有什么限制、还差什么」。

## 一、产品是什么

给本地生活商家（探店、餐饮、美业、门店）用的 AI 创作工具，在 App 里一站完成**写文案、做数字人、出图文、出海报、拍视频**。
所有生成类功能都走同一套规则：提交后立刻返回、后台异步生成、前端轮询结果、成品自动进素材库。

## 三、各功能怎么用

### 3.1 店铺档案

- 一个账号最多 20 条档案。
- 字段：店铺名称（必填）、开店时间、地址、提供商品或服务、核心卖点、如何称呼自己、主要目标客群。
- 字数上限按设计稿，汉字算 2 个字符。
- 已接入：AI文案、图文笔记、探店视频、带货短剧。生成时自动把档案拼进提示词，开店时间会顺带算出「已开店几年几个月」。
- 删除是逻辑删除，已生成的内容不受影响。

### 3.2 AI文案

- 三条路径：**AI帮写**（给要求让 AI 写）、**爆款仿写**（贴一篇仿写）、**自主撰写**（自己写了保存）。
- 支持 AI 优化、重新生成、列表搜索和按状态筛选、详情编辑、删除。
- **生成历史**：每条文案能看到它被拿去生成过哪些成品，只显示已完成的。前提是前端提交时带上文案编号。
- AI帮写还服务于别的功能的「帮写」按钮，场景包括：数字人配音词、口播、海报信息、长图内容、笔记主题、探店、短剧。
- 有内容审核（关键词），提示词和选项都在后台可配。

### 3.3 AI数字人

流程：选形象 → 选音色 → 写配音词（50 字以内）→ 生成 → 存为「我的数字人」。

- **形象三种来源**：上传照片、公共数字人（小林、阿杰、小雅、小北，运营可增减）、AI 定制。
- **AI 定制形象**：选性别、年龄、肤色、职业，再写 200 字以内的创意描述，一次出 4 张 9:16 的图供选，可重新生成。
- **音色**：只做系统音色，按分类展示，每个可试听。**不做「我的音色」**（录音克隆、自定义音色）。
- **出片模型两档**：Seedance 2.5（云端，快）和 lite（本地 GPU，慢）。时长取配音实际长度，lite 最长 25 秒。固定 9:16、720p。
- 首次生成前要同意《AIGC 功能使用约定》，约定改版后需重新同意。

### 3.4 数字人口播

- 输入：口播文案（字数不限）+ 人物图 + 背景。
- 人物图来源同动作迁移：上传、公共数字人、AI 定制。
- 背景三种：AI 智能匹配、预设背景（运营维护）、自己导入。
- 时长 15 或 30 秒，比例 9:16 或 16:9，分辨率固定 720p。
- 剧本由执行面内部生成，没有「规划剧本」页。生成完不跳转，只返回数据，跳转由前端决定。

### 3.5 动作迁移

- 输入：人物图 + 动作视频。动作视频可选运营预置的，也可导入自己的。
- 云端走高质量档，选 lite 走本地。成品封面用人物图。

### 3.6 AI图文笔记

流程：填表单 → AI 构思 → 规划页确认 → 出图 → 详情和编辑。

- 表单：笔记类型、主题、素材（最多 3 张）、数字人、店铺档案、套图数量（以前端为准，不设上限）。
- **构思**产出标题、正文、话题标签，以及每张图的出图要求。
- **规划页**可改标题和正文，套图数量只能改少，不能改多。
- 编辑页图片上限 6 张，生成张数更多时按生成张数算。
- 已知限制：图片上的文字在构思时就定了，规划页改标题不会改图上的字。

### 3.7 AI海报 / AI长图

- 填内容（500 字以内）→ 选模板（必选）→ 生成设置 → 提交。
- 海报：模板可按类型筛（社媒、营销、节日、喜庆、邀请函、招聘），可选风格和比例，默认 2:3。
- 长图：比例固定 1:3。
- 上传素材最多 3 张。
- 一次可出多张。部分成功时按完成处理，只返回成功的那几张；全部失败才算失败。
- 模板下架不影响已生成的记录。

### 3.8 探店视频 / 带货短剧

**两步流程**：填表单 → 出剧本 → 规划剧本页（只读，可重新生成）→ 确认出片 → 成品。

| | 探店视频 | 带货短剧 |
|---|---|---|
| 必填 | 文案 | 主题、**商品图** |
| 可选素材 | 门店图、店内图、道具图 | 商品卖点、环境图、出镜人物 |
| 出镜人物 | 数字人三种来源 | 同左 |
| 店铺档案 | 可关联 | 可关联 |

- 出片模型：Seedance 2.5（云端，默认）或 lite。
- 状态：构思中、待确认、生成中、已完成、失败。
- 剧本页只读，确认时原样交给出片，不能手改。

### 3.9 爆款视频复刻

- 两种来源：**上传本地视频**，或**粘贴分享链接**（抖音、快手、小红书、B 站，自动识别平台）。
- 源视频限制：50M、3 分钟以内。体积和格式在提交时校验，时长在解析后校验，超了会提示且不扣钱。
- 流程：解析出剧情文本 → 确认 → 复刻出片。成品进素材库「视频复刻」分类。

## 四、配套能力

| 能力 | 说明 |
|---|---|
| 登录 | App 带联盟的临时 token 换本服务令牌，没有账号自动建档，每次登录同步昵称、头像、手机号。令牌 7 天有效 |
| 素材库 | 所有成品自动入库，按功能分类，App 素材库页由现有系统提供 |
| 任务中心 | 本地生活的任务同步进现有任务中心，能在列表里看到并按入口筛选。任务中心的「取消」不会真正停掉我们的任务 |
| 上传 | 前端直传阿里云 OSS，后端只发临时凭证并校验地址属于自己的目录。大小和类型由前端控制 |
| 内容审核 | 文案类输入做关键词审核 |
| 运营后台 | 用现有后台账号登录。公共数字人、海报和长图模板、预置动作视频、口播背景由运营在现有「模板」里维护；音色、提示词、选项可配 |
| 批量导入 | 工具支持批量导入公共数字人、模板、动作视频，可重复执行 |

## 五、生成耗时与超时

超过超时时间未出结果，任务判失败，提示「生成超时，请重试」。

| 功能 | 步骤 | 超时 |
|---|---|---|
| 海报、长图 | 出图 | 20 分钟 |
| 图文笔记、数字人形象 | 构思、出图 | 10 分钟 |
| 数字人口播 | 出片 | 60 分钟 |
| 探店视频、带货短剧 | 出剧本 | 10 分钟 |
| 探店视频、带货短剧 | 出片 | 60 分钟 |
| 爆款视频复刻 | 解析 | 30 分钟 |
| 爆款视频复刻 | 出片 | 180 分钟 |
| 动作迁移、AI数字人 | 出片 | 40 分钟 |

参考：本地 GPU 出 15 秒口播实测约 14 分钟，云端更快。

## 六、产品已做的决定

- 图片统一按一张算，上传素材最多 3 张，笔记编辑上限 6 张，海报默认 2:3，长图固定 1:3。
- 视频云端两档：Seedance 2.0 用于动作迁移和视频复刻，Seedance 2.5 用于探店、短剧、口播、数字人；lite 为本地模型。
- 计费口径：**图片类用 GPT Image 2，沿用现成的 creaft 价，之后再调**；**AI文案不计费**；视频类和电商共享能力码。
- 数字人**不做「我的音色」**。
- 开发范围只按 AIGC 任务对接文档里的任务，设计稿上的其他板块不在本期。

## 八、已知限制

- 笔记图片上的文字不会随规划页改标题而变。
- lite 数字人最长 25 秒，口播和复刻的 lite 档速度明显慢于云端。
- 任务中心的「取消」只改列表状态，不会真停止生成，下一轮会按真实状态改回。
- 生成产物先落在上游私有桶，转存到我们的公有桶后才可访问，转存失败会保持「生成中」并重试。
- 文字类 AI 能力（帮写、文案、笔记构思、剧本）依赖百炼大模型账号，账号欠费或停用时会被拒，图片和视频生成不受影响。
