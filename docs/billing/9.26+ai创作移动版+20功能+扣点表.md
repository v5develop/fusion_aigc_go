## 算法口径

- ~~1 积分 = 0.1 元~~ → 现行 **1 积分 = 0.01 元**
- 图片功能全部走 **GPT Image 2**，一张 0.1 元（旧口径记 1 积分，已作废）
- **sd2.0（Seedance 2.0）= 0.8 元/秒 = 8 积分/秒**；**sd25（Seedance 2.5）= 1.1 元/秒 = 11 积分/秒**
- **动作迁移、视频复刻 → 只用 sd2.0**；**探店、短剧、口播、数字人 → 只用 sd25**
- **lite（本地模型）= sd2 的 8 折 = 0.64 元/秒 = 6.4 积分/秒**（六个视频功能统一）
- 视频复刻在 sd2.0 之外多 0.4 元/秒（千问3-VL + 百炼 ASR + 图片资产打包）
- 剧本 / 提示词 / 解析这些环节即使走 lite 也还是走百炼（线上）
- **视频生成先空着**（不在这份对接文档里）
