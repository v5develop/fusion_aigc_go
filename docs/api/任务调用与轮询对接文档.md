# 任务调用与轮询对接文档（9 / 70 / 71 / 72 / 73 / 74 / 75 / 76 / 78 / 85 / 87 / 88 / 92）

## 一、通用调用流程

### 1. 提交任务

```http
POST /aigc/generate
Content-Type: application/json

{
  "task_id": "ecommerce_xxx",
  "task_type": 85,
  "...": "任务专属参数, 见下文"
}
```

请求体支持小驼峰；成功返回（HTTP 200）：

```json
{"code":200,"message":"success","success":true,
 "data":{"task_id":"ecommerce_xxx","task_type":85,"queue_length":3}}
```

- 参数错误返回（HTTP 400）：`{"code":400,"message":"task_type=85 缺少 image_path","success":false}`
- ⚠️ `data.task_type` 是**路由后**的类型，可能与请求不同：`9 + model=lite → 9`（`9` 缺省/其它 model → 云端 86）、`71 + model=lite → 83`、`73 + model 缺省/seedance2.5 → 81`（`73 + model=lite` 才是本地 GPU 73）、`85 + model=lite → 45`、`88 + model 缺省/seedance2.5 → 89`（`88 + model=lite` 才是本地 GPU 88）、`92 + model=lite → 91`（`92` 缺省/seedance2.5 才是云端 92）。

### 2. 轮询结果

```http
GET /aigc/getRes/{task_id}
```

| 返回 `status` | 含义                                                                   |
| ------------- | ---------------------------------------------------------------------- |
| `waiting`     | 已入队，未开始                                                         |
| `running`     | 生成中                                                                 |
| `success`     | 完成，见下方产物字段                                                   |
| `failed`      | 失败，含 `error_msg`/`error_code`/`upstream`/`pool`/`cost`/`traceback` |
| `not_found`   | 查不到（结果只保留**今天+昨天** 2 天）                                 |

**产物字段（按任务不同）**

| 字段                   | 说明                           | 涉及任务                             |
| ---------------------- | ------------------------------ | ------------------------------------ |
| `generated_image_path` | 单个产物，**OSS 可访问 URL**   | 9 / 71 / 73 / 76 / 78 / 85 / 88 / 92 |
| `image_paths`          | 多个产物，OSS URL 数组         | 75                                   |
| `script`               | 结构化文本/JSON 结果（无文件） | 72 / 74 / 87                         |
| `text` / `duration`    | 解析文本 + 时长（无文件）      | 70                                   |

### 3. 可选：结果回调

提交时带 `taskGroupId`，平台会在任务终态后回调（平台侧配置）。

### 4. 队列（影响耗时）

| 队列                                  | 任务                                                                                         |

## 三、各任务详细参数

### 9 动作迁移

```json
{
  "task_id": "ecommerce_xxx",
  "task_type": 9,
  "input_video": "http://xx-shop-img.oss-cn-hangzhou.aliyuncs.com/tmp/001/s13.mp4",
  "reference_image": "http://xx-shop-img.oss-cn-hangzhou.aliyuncs.com/tmp/001/nvnv.png",
  "prompt": "跳舞",
  "duration": 15,
  "resolution": "720p",
  "aspectRatio": "9:16"
}
```

| 字段                                      | 必填                     | 说明                                                                                                                                                                       |
| ----------------------------------------- | ------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `input_video`                             | ✅                        | 驱动视频；**公网 URL 或 OSS key 都支持**                                                                                                                                   |
| `reference_image`                         | ✅                        | 参考角色图；同上                                                                                                                                                           |
| `model`                                   | 选填                     | **缺省 / 任意其它值 → 路由到 86**（Seedance 2.0，两个字段**必须是公网 URL 且原样透传**）；**`lite` → 走 9**（本地 GPU 动作迁移，公网 URL 会自动下载，否则按 OSS key 下载） |
| `prompt`                                  | 选填                     | 默认 **跳舞**                                                                                                                                                              |
| `duration` / `resolution` / `aspectRatio` | 选填(实际时长以视频为准) | 走 86 时生效：默认 15 / `720p` / `9:16`；走 9（本地）时用 `positive_prompt`(默认 跳舞)、`frame_load_cap`(默认 257)、`custom_width/height`(默认 720×1280) 等                |

产物：`generated_image_path` = mp4（OSS URL）。

### Python 串两步（含轮询）

```python
import time, requests

BASE = "http://<host>:5000"

def submit(payload):
    r = requests.post(f"{BASE}/aigc/generate", json=payload, timeout=30)
    r.raise_for_status()
    return r.json()["data"]["task_id"]

def wait(task_id, interval=8, timeout=1800):
    deadline = time.time() + timeout
    while time.time() < deadline:
        data = requests.get(f"{BASE}/aigc/getRes/{task_id}", timeout=30).json()
        if data.get("status") in ("success", "failed"):
            return data
        time.sleep(interval)
    raise TimeoutError(task_id)

# 数字人口播 92（30s）
tid92 = submit({"task_id": "ecommerce_voice92_001", "task_type": 92,
                "text": "欢迎光临我们的小店，今天给大家推荐一款超好用的洗面奶。",
                "CHAR_01_url": "https://<公网>/person.png",
                "ENV_01_url": "https://<公网>/scene.png",
                "duration": 30, "aspectRatio": "9:16"})
res92 = wait(tid92, timeout=1800)          # 云端 92 约 2–10 分钟
print(res92["task_type"], res92["generated_image_path"])
```
